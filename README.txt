GhostTab Privacy Policy — free GitHub Pages hosting

Branding included: Ghost Interactive, Ghost Studios, and the existing Ghost Studios monogram mark. logo.png is a 300 x 300 square company/product logo suitable for the Microsoft Edge Add-ons Extension logo field. brand-mark.png is the compact mark used in the privacy-page header.

1. Create a PUBLIC GitHub repository named: ghosttab-privacy
2. Upload index.html, logo.png, and brand-mark.png to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait until GitHub Pages shows the published link. The URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/ghosttab-privacy/
7. Open the link in a private/incognito window to make sure it is public.
8. Paste that published URL into the Privacy policy URL field in Microsoft Partner Center.

Store portal branding is separate from the privacy form: set Publisher display name in Partner Center Developer settings/Contact info, and upload logo.png under Store listings > your language > Edit details > Extension logo. The browser toolbar icon remains the GhostTab icon packaged inside the extension.

Before publishing, review the policy and make sure it matches the exact extension package you submit. If you remove the Weather feature or change other data flows, update the policy and Partner Center disclosures.
